## Planned

- **OpenTelemetry observability.** Optional distributed tracing and metrics for the task lifecycle and HTTP requests, through `@opentelemetry/api`. It would be a no-op by default, with zero cost unless a host application registers a real SDK or exporter. Not yet implemented.

## Influence the roadmap

Open an issue or a discussion on [GitHub](https://github.com/shashikanth-gs/a2a-wrapper). Pull requests are welcome; see [contributing](/docs/community/contributing).
