Everything on this site is available in forms that AI assistants and coding agents can read without scraping HTML.

## llms.txt and llms-full.txt

| URL | What it is |
|---|---|
| [`/llms.txt`](/llms.txt) | A short index of every page with its description and link, following the [llms.txt](https://llmstxt.org) convention |
| [`/llms-full.txt`](/llms-full.txt) | The full text of all pages in one Markdown file, for loading into a long context |

Point your assistant at `/llms.txt` so it can find the right page, or paste `/llms-full.txt` when you want it to know the whole project.

## Markdown for every page

Append `.md` to any docs URL to get that page as clean Markdown:

```bash
curl https://a2a-wrapper.allsrc.dev/docs/getting-started/quickstart.md
```

You can also ask for Markdown with the `Accept` header. The same URL then returns Markdown instead of HTML:

```bash
curl -H 'Accept: text/markdown' https://a2a-wrapper.allsrc.dev/docs/getting-started/quickstart
```

This is content negotiation, so crawlers and agents that request Markdown get it automatically.

## Copy as Markdown, and open in an assistant

Every page has a **Copy Markdown** button and an **Open** menu that hands the page to an assistant or to GitHub, so you can ask questions about the page you are reading.

## Docs MCP server

Coding agents can query these docs directly through an [MCP server](/docs/ai/mcp-server) at `/mcp`, with tools to search pages and read them.

## Why this matters for a2a-wrapper

The wrappers exist so agents can work with agents. The documentation follows the same idea: an agent that is asked to set up an A2A server should be able to read the docs itself and get it right.
