The documentation is also available as a read-only [MCP](https://modelcontextprotocol.io) server. Your coding agent can search the docs and read pages on its own while it works.

**Endpoint:** `https://a2a-wrapper.allsrc.dev/mcp` (Streamable HTTP, stateless, no authentication, read-only)

## Connect

<Tabs items={['Claude Code', 'Other clients']}>
<Tab value="Claude Code">

```bash
claude mcp add --transport http a2a-wrapper-docs https://a2a-wrapper.allsrc.dev/mcp
```

</Tab>
<Tab value="Other clients">

Add a remote HTTP MCP server with the URL above. The exact configuration varies by client, for example:

```json
{
  "mcpServers": {
    "a2a-wrapper-docs": { "url": "https://a2a-wrapper.allsrc.dev/mcp" }
  }
}
```

</Tab>
</Tabs>

## Tools

| Tool | Arguments | Returns |
|---|---|---|
| `search_docs` | `query` (string), `limit` (number, default 5) | Matching pages with path, description and URL, best match first |
| `get_page` | `path` (string), for example `getting-started/quickstart` | The full Markdown of that page |
| `list_pages` | none | Every page with its path, title and description |

## Try it with curl

```bash
curl -s https://a2a-wrapper.allsrc.dev/mcp -H 'content-type: application/json' -d '{
  "jsonrpc": "2.0", "id": 1, "method": "tools/call",
  "params": { "name": "search_docs", "arguments": { "query": "sandbox mode" } }
}'
```

## Notes

- The server is stateless and read-only. It never writes anything.
- It returns the same content as [`/llms-full.txt`](/docs/ai), organised for retrieval.
- For the project's own agents, this is separate from the [sub-agent MCP bridge](/docs/concepts/sub-agents), which connects a2a-wrapper agents to other agents.
