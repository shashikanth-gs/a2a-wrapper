"@a2a-wrapper/core": minor
---

Add the core-owned domain model and an A2A v1 adapter (additive, no existing export changed). New SDK-free types: `CorePart` (open union with an `unknown` member), `CoreTaskState`, `CoreRequest`, `CoreMessage` with `queue`/`steer`/`interrupt` delivery, `CoreInteraction` and `CoreInteractionResult`, `CoreUsage`, `SteerOutcome`, `AbortOutcome`, the `PendingInteraction`/`ContextBinding`/`RunRecord` persistence records, and the `ProviderExecutor` contract (`CoreTaskRun` is the provider-facing run). The adapter (`fromA2APart`, `toA2APart`, `fromA2ATaskState`, `toA2ATaskState`, `coreRequestFromContext`, `toStatusUpdate`, `toArtifactUpdate`, `renderInteraction`, `parseInteractionReply`, and friends) is the only new module that imports `@a2a-js/sdk`; unknown parts and task states round-trip instead of being dropped, and `isApproval` approves only an explicit `allow_*` selection.

Review fixes to the same model (still unreleased, so folded in): a task is a sequence of turns (`queue` and `interrupt` run as the next turn of the same task, `SteerOutcome` has `queued`, `DeliveryResult` names task, message and holder, `abort` takes a reason, `CoreRequest` has `turnId`); a provider cannot name a task state (`CoreTaskRun.status` is replaced by `progress`, `reject` is added, `classifyState` makes callers handle unknown states, `TASK_STATE_UNSPECIFIED` is never sent); records carry a versioned owner header, are JSON-safe and round-trip through `encodeRecord` / `decodeRecord`; `CoreInteraction` is a union checked by `normalizeInteraction`, with withdrawal, a per-task FIFO, reply codes for text approvals and a fix for free-form "no" answers; `usageDelta` converts running totals to deltas per series and model with reset detection; adapter wire keys are versioned (`urn:a2a-wrapper:<name>:v1`), listed in `WIRE_EXTENSIONS` and declarable with `agentExtensionDeclarations`, with the old keys still read inbound. Second round: `CoreTaskRun.beginHeldTurn` / `dropHeld` for provider-held messages (a task is terminal only when nothing is queued or held), strict record codec (`$bytes:v1` marker, non-plain values throw), four-character `replyCode` salted by id and `seq`, `QueuedMessageRecord`, `OrphanInfo`, and a typed `signal.reason`.
